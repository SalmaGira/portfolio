# Salma Gira — Portfolio

Welcome! This is my personal portfolio, built with React, TypeScript, and Vite, showcasing my projects, skills, resume, and contact information.

---

## 🚀 Overview

A modern, responsive portfolio for Salma Gira, Full-Stack Engineer.  
Features a clean design, animated sections, project cards, organized resume, and easy contact options.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite, Framer Motion, React Icons, CSS Modules
- **Styling:** Modern CSS, accent colors, responsive layout
- **Animations:** Framer Motion for smooth transitions

---

## ✨ Features

- **Home:** Introduction & title
- **Projects:** Card-based, animated grid of selected works
- **Resume:** Grouped skills, detailed experiences, education, languages
- **Contact:** Social links and email
- **Theme Toggle:** Light/dark mode
- **Fun Facts:** (optional) Personal, creative highlights

---

## 📦 Getting Started

### Clone & Install

```bash
git clone https://github.com/SalmaGira/portfolio.git
cd portfolio
npm install
```

### Run Locally

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view the site.
